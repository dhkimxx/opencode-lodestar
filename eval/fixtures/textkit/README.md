# textkit

Small string helpers.

## API

- `capitalizeWords(text)`: upper-cases the first letter of every word.
- `reverseWords(text)`: reverses the order of the words.
- `padCenter(text, width, fill?)`: centers text in a field.
- `countVowels(text)`: counts the vowels.
- `formatName(name)`: formats a person's name for display.
- `banner(title, width?)`: a boxed title for terminal output.

Run the tests with `bun test`.
